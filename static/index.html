Why this score

    Bars show each feature's push on this customer's score, measured against its baseline category (e.g. a month-to-month contract or "no add-on" shows no push). Correlated features, like monthly charges and add-on services, can show surprising signs.

    Retention ideas to test

      These come from patterns in past data, which are associations, not proven causes. Test them before rolling out.

      How it works

      1

      A transparent model

      A class-balanced Logistic Regression trained on the Telco customer churn dataset. It was picked on cross-validation, within noise of Random Forest and XGBoost on ROC-AUC, but far easier to explain.

      2

      A business-tuned threshold

      Missing a churner costs more than sending an unneeded offer, so the cutoff is lowered from 0.50 to 0.29 using assumed offer and customer-value costs.

      3

      A score, not a promise

      Because the model is class-balanced, the score ranks customers well but is not a literal probability. Use it to prioritise outreach, not to forecast exact churn rates.
